# AI103-E2.03 — Implement analyzers for generating structured or markdown outputs for downstream reasoning by using Content Understanding

Parent: AI103-E2; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Create a version-compatible analyzer that produces the intended schema fields or markdown representation.

Use ContentUnderstandingClient, analyzer_id and long-running polling; configure fields/models/defaults and retain the GA/preview distinction.

## Failure or distractor distinction

A retired analyzer property can break migration; returning the initial operation response is not the final extracted document.

## Scenario judgment

A downstream rules engine benefits from typed extracted fields, while a RAG workflow also needs readable structured markdown and provenance.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
