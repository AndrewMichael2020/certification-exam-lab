# AI103-A1.03 — Choose an appropriate method for retrieval and indexing

Parent: AI103-A1; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use keyword retrieval for exact terms, vectors for conceptual matches, and hybrid retrieval when both matter; semantic ranking is a separate relevance step.

Provide searchable text/vector fields; match query/index embeddings; add a semantic configuration for semantic queries.

## Failure or distractor distinction

Changing only the answer model cannot restore a missing product-code match in the retrieved evidence.

## Scenario judgment

For queries mixing part identifiers with paraphrased symptoms, hybrid retrieval is justified by complementary exact and semantic evidence.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
