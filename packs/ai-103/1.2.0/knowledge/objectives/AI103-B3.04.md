# AI103-B3.04 — Orchestrate multiple models, flows, or hybrid LLM and rules engines

Parent: AI103-B3; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use model routing for eligible model choice and workflow/rule control for deterministic decisions or multi-step orchestration.

Restrict router model sets to allowed capabilities; enforce business constraints in code; evaluate quality/cost tradeoffs.

## Failure or distractor distinction

A router selects a model; it does not automatically encode all application rules or a complete agent workflow.

## Scenario judgment

An eligibility rule should run deterministically before an LLM explains it; router choice can optimize the explanation stage.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
