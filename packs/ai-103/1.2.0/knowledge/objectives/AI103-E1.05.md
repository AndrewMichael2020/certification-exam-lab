# AI103-E1.05 — Connect retrieval pipelines directly to workflows and agent tools

Parent: AI103-E1; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Connect the finished retrieval pipeline to a documented Search tool or application function used by workflows/agents.

Supply project connection/index, supported query_type and filters; use managed identity for private Search tool connections; retain citations.

## Failure or distractor distinction

Attaching a tool does not ingest missing documents or grant every downstream permission.

## Scenario judgment

If an agent can query an empty or stale index, fix ingestion/index quality before changing the tool schema.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
