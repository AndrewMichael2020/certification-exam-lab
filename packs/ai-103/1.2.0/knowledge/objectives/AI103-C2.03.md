# AI103-C2.03 — Implement a solution that enables question‑answering grounded in visual evidence

Parent: AI103-C2; domain: C; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Ground the answer in the supplied visual input and retain available extraction/source references.

Pass images to the visual model or use CU extraction with source coordinates/spans where supported; request uncertainty when evidence is absent.

## Failure or distractor distinction

Model-generated spatial descriptions are not automatically validated bounding-box detections.

## Scenario judgment

When reading a scanned table, verify the answer against the relevant cells/source coordinates instead of trusting a plausible total.
