# AI103-B1.02 — Implement retrieval-augmented generation (RAG) in an application

Parent: AI103-B1; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Build RAG as retrieve relevant evidence, assemble grounded context, generate the answer, and retain citations.

Ingest/chunk/embed data; configure index and query; connect retrieval to generation; evaluate grounding and relevance separately.

## Failure or distractor distinction

RAG reduces reliance on model memory but retrieved irrelevant content can still yield a polished wrong answer.

## Scenario judgment

A correct policy answer must be supported by retrieved current clauses, not merely sound plausible.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
