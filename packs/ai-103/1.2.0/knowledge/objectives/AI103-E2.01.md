# AI103-E2.01 — Extract information by using multimodal pipelines that combine OCR, layout analysis, and field extraction

Parent: AI103-E2; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Combine content extraction/OCR/layout with field schema extraction, preserving the source of each required value.

Use compatible CU/Document Intelligence layout paths; configure the field schema and source/confidence estimation; validate representative documents.

## Failure or distractor distinction

OCR alone returns text, while layout and field extraction preserve structure and target semantics; neither is a guarantee of perfect accuracy.

## Scenario judgment

For invoices, verify the amount/currency/date fields against source locations and route uncertain fields for review.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
