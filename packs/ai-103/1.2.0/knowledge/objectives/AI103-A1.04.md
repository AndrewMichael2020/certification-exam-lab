# AI103-A1.04 — Choose appropriate memory, tool, and knowledge integration services for agent solutions

Parent: AI103-A1; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Choose conversation state for the active interaction, long-term memory for persistent personalization, file search for uploaded material, and curated retrieval for organizational knowledge.

Define memory scope and retention; attach appropriate retrieval/function tools; check preview network limitations.

## Failure or distractor distinction

A persistent memory store without user scoping risks cross-user context leakage; memory is not policy authority.

## Scenario judgment

A returning user's preferred units belong in scoped memory; a company safety rule belongs in the curated knowledge base.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
