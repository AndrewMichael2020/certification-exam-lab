# AI103-C2.05 — Implement visual understanding by configuring Azure Content Understanding in Foundry Tools to extract visual characteristics

Parent: AI103-C2; domain: C; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Configure Content Understanding to extract image characteristics or a specified schema rather than unrestricted free-form guessing.

Select an eligible image/document analyzer and fields; choose GA or preview API explicitly; use documentSearch for text-bearing images per the SDK reference.

## Failure or distractor distinction

Using an image-description analyzer for an image containing important text can lose the required document structure.

## Scenario judgment

A catalog image description and a photo of an invoice should use analyzers suited to their different downstream representations.
