# AI103-A1.02 — Choose the appropriate Foundry services for generative tasks, grounding, vector search, agent workflows, or multimodal processing

Parent: AI103-A1; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use a model for generation, Search for indexed retrieval, Content Understanding for multimodal extraction, and agent orchestration for tools and control flow.

Convert content to usable representations; configure embeddings/indexes or analyzer schemas before attaching them to agent tools.

## Failure or distractor distinction

Conversation memory is not a maintained organizational knowledge corpus; a model prompt is not an indexer.

## Scenario judgment

A policy agent must retrieve current policy documents while remembering user language: keep curated content in retrieval and personal preference in scoped memory.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
