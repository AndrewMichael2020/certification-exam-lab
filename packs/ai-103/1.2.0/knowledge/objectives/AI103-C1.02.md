# AI103-C1.02 — Implement a solution that generates videos from text prompts and reference media

Parent: AI103-C1; domain: C; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use the Sora 2 preview video API for text/image-conditioned generation when the use case and model policy permit it.

Create the video job, wait/poll for completion, and obtain generated output; keep current v1 methods separate from older jobs API samples.

## Failure or distractor distinction

A creation acknowledgement is not the completed video; model policy restrictions can block apparently reasonable content.

## Scenario judgment

For an asynchronous creative workflow, persist job identity and status so the user can resume retrieval after a delay.
