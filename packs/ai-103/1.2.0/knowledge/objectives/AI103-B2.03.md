# AI103-B2.03 — Integrate agent tools, including APIs, knowledge stores, search, content understanding, and custom functions

Parent: AI103-B2; domain: B; **partial** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use supported tool connections for Search and custom function wrappers for application APIs; a Content Understanding operation can supply extracted representations.

Configure connection/index parameters or function schemas; account for CU long-running polling; validate tool results and provenance.

## Failure or distractor distinction

A client SDK being callable does not prove a native agent-tool integration exists or provides automatic permission checks.

## Scenario judgment

A document-extraction function should wait for the CU result and return only needed grounded fields to the agent.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
