# AI103-A2.01 — Design Azure infrastructure for AI apps and agent-based solutions

Parent: AI103-A2; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Select basic or customer-managed standard agent storage according to control/residency needs, then design project and dependency connectivity.

Separate provisioning identity from runtime access; plan secured dependency endpoints/DNS when private networking is required.

## Failure or distractor distinction

A private Foundry endpoint alone does not prove all downstream storage/search traffic follows the intended path.

## Scenario judgment

For a company requiring subscription-owned state and private dependencies, start with the documented standard secured setup and inspect every dependency.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
