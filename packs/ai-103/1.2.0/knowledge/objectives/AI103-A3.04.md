# AI103-A3.04 — Configure security, including managed identity, private networking, keyless credentials, and role policies

Parent: AI103-A3; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use Entra identities with scoped RBAC and documented private-network connections for least-privilege operation.

Assign access to both the caller and project/runtime identity as required; configure dependency networking/DNS; avoid embedding keys.

## Failure or distractor distinction

Granting a role to the developer does not automatically grant the project identity access; key-based access bypasses Foundry RBAC restrictions.

## Scenario judgment

A private Search tool connection must use the documented project managed identity; replacing it with an API key does not satisfy that private connection contract.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
