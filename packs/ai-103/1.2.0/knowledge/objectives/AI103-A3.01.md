# AI103-A3.01 — Manage quotas, scaling, rate limits, and cost footprints for model and agent workloads

Parent: AI103-A3; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Diagnose model limits separately from agent/session and managed-compute quotas; control concurrency and resource lifetime.

Inspect the error code; use bounded exponential backoff with jitter; measure token usage and consider capacity appropriate to sustained load.

## Failure or distractor distinction

Blind retries do not fix persistent exhausted quota or leaked active sessions.

## Scenario judgment

For repeated 429 errors, distinguish session limits from model throughput before choosing cleanup, capacity change, or retry.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
