# AI103-B2.01 — Define agent roles, goals, conversation-tracking approach, and tool schemas

Parent: AI103-B2; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Define the agent's purpose and instructions, conversation lifecycle, and tool names/descriptions/JSON schemas.

Use one compatible agent-definition API; decide whether state is per conversation or persistent memory; ensure required argument types are explicit.

## Failure or distractor distinction

Vague overlapping tool names make tool selection harder, and long-term memory should not be confused with the current conversation.

## Scenario judgment

A refund assistant needs a specific refund function schema and a clearly scoped conversation, not a generic unrestricted 'run action' tool.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
