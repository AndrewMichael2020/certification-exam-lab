# AI103-A4.04 — Govern agent behavior with oversight modes, constraints, and tool-access controls

Parent: AI103-A4; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Enforce tool permissions in the application/runtime and use explicit oversight at meaningful action boundaries.

Validate arguments; allowlist tools/operations; require appropriate approval; inspect tool-call and tool-response controls.

## Failure or distractor distinction

A prompt saying 'be careful' does not implement runtime authorization or prevent an unrestricted tool from changing data.

## Scenario judgment

A billing agent may inspect invoice data freely within scope while a payment action requires a validated amount and an approval boundary.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
