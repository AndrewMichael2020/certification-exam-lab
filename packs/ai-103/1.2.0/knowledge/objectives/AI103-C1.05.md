# AI103-C1.05 — Select and apply appropriate generation and editing controls provided by the platform

Parent: AI103-C1; domain: C; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Apply only controls documented for the chosen model and modality.

Compare image size/quality/format/count and video duration/resolution/reference support within the same API generation; preserve access and content restrictions.

## Failure or distractor distinction

Copying one image model's quality enum to another model or applying image controls to video causes invalid requests.

## Scenario judgment

A latency-sensitive image prototype and a detailed final edit can use different valid quality settings, verified against that deployment's capability table.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
