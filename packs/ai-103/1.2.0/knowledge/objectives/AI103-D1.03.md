# AI103-D1.03 — Build solutions that translate text by using Azure Translator in Foundry Tools or LLM‑powered translation flows

Parent: AI103-D1; domain: D; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use Translator for documented translation modes and customizable terminology; use an LLM flow only with evaluated task-specific instructions.

Select text versus document mode, source/target language, supported customization, and output validation; retain terminology and source context.

## Failure or distractor distinction

Text, synchronous-document and asynchronous-document translation differ in input, formatting and storage; a generic LLM rewrite can alter required terminology.

## Scenario judgment

For a batch of documents with domain terminology, use an eligible document/custom translation workflow rather than assuming a generic chat reply preserves structure and vocabulary.
