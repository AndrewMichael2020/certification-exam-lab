# AI103-A1.01 — Choose an appropriate model for each task, including large language models (LLMs), small language models, multimodal models, and Foundry Tools

Parent: AI103-A1; domain: A; **partial** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Match the task's input/output modality and needed tools before optimizing cost/latency; benchmark an eligible model against representative examples.

Check model support, endpoint family, deployment route, and residency; use model router only within the permitted model subset.

## Failure or distractor distinction

A text-only or unsupported-tool model cannot satisfy a visual/task contract merely because it has a larger name.

## Scenario judgment

For a low-cost text classifier versus a chart-analysis agent, first separate modality/schema/tool requirements, then measure quality and cost.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
