# AI103-D2.04 — Translate speech into other languages by using language models and Foundry Tools

Parent: AI103-D2; domain: D; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use Speech translation for recognized source speech to target text/speech, or an explicitly evaluated audio/LLM translation flow.

Configure source recognition language and each target language; inspect recognition status; synthesize the chosen target voice separately when needed.

## Failure or distractor distinction

Target-language text and target-language audio require distinct handling; NoMatch/Canceled are not successful translations.

## Scenario judgment

A multilingual agent should retain recognized source text, translated outputs, and cancellation details to diagnose the correct stage.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
