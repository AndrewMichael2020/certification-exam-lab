# AI103-B2.06 — Integrate monitoring into deployed agents, evaluate agent behavior, and perform error analysis

Parent: AI103-B2; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Trace the agent's actual sequence and evaluate whether tools and final deliverables fulfilled the task.

Correlate spans and evaluator runs; inspect tool selection/argument/output failures and latency; separate runtime errors from reasoning errors.

## Failure or distractor distinction

A tool returning 200 does not prove its parameters were correct or the result was used.

## Scenario judgment

When an agent chooses a weather tool for an inventory question, use the trace plus tool-selection evaluation to isolate the mistake.
