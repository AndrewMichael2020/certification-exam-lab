# AI103-E1.04 — Configure RAG ingestion flow, including documents and using optical character recognition (OCR)

Parent: AI103-E1; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Combine readable document extraction/OCR, meaningful chunking, embeddings, and index projection for RAG.

Configure imageAction/normalized image paths, OCR/layout outputs, chunk source metadata, and embedding compatibility; inspect indexer failures.

## Failure or distractor distinction

OCR can create text without preserving document structure; layout-aware chunking may be needed for tables/sections.

## Scenario judgment

A scanned manual should retain headings and page context so retrieved chunks do not separate warnings from the instructions they qualify.
