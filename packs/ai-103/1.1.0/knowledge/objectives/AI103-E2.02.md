# AI103-E2.02 — Produce clean, grounded representations to use with agents and RAG by using Content Understanding

Parent: AI103-E2; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Produce clean RAG/agent content while retaining its page, coordinate, span, and document lineage.

Select the documentSearch analyzer/markdown output; preserve structure and references in chunk metadata; choose review thresholds from representative validation.

## Failure or distractor distinction

Discarding source references during cleanup makes a polished answer harder to verify; confidence is not an unconditional accuracy promise.

## Scenario judgment

A contract chunk should carry its document/page/clause context so the agent can support a citation and a reviewer can find the passage.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
