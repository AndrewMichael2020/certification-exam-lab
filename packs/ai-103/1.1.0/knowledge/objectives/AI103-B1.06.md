# AI103-B1.06 — Configure an application to connect to a Foundry project

Parent: AI103-B1; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Construct AIProjectClient with the project endpoint and an authenticated Entra credential.

Use `https://<resource>.services.ai.azure.com/api/projects/<project>`; verify caller RBAC and model deployment access; get the OpenAI client from the project when required.

## Failure or distractor distinction

An Azure OpenAI model root is not a project endpoint, and a Foundry API key is not the captured AIProjectClient authentication method.

## Scenario judgment

If authentication succeeds but project operations fail, verify project identity/scope and endpoint before adjusting generation parameters.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
