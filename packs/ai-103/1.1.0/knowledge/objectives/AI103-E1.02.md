# AI103-E1.02 — Configure semantic search, hybrid search, and vector search for grounding

Parent: AI103-E1; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Choose keyword, vector, hybrid, and optional semantic ranking according to relevance requirements.

Match indexed/query embeddings; configure vector fields and semantic settings; preserve filters and avoid explicit sorting that replaces relevance.

## Failure or distractor distinction

Semantic ranking is not the same as creating embeddings; pure vectors can miss exact identifiers.

## Scenario judgment

For product-code questions plus paraphrased symptoms, hybrid retrieval lets exact and conceptual evidence contribute before reranking.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
