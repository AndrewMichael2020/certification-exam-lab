# AI103-B3.03 — Set up observability by implementing tracing, token analytics, safety signals, and latency breakdowns

Parent: AI103-B3; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use nested traces to break down model/tool latency and relate usage and safety events to individual requests.

Export to the connected Application Insights resource; correlate IDs/version metadata; redact sensitive inputs; inspect token/billing dimensions supported by the service.

## Failure or distractor distinction

Aggregate request duration alone hides slow retrieval or repeated calls; trace content can reveal secrets.

## Scenario judgment

A slow answer with three redundant retrieval calls needs span-level timing and tool analysis before increasing deployment capacity.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
