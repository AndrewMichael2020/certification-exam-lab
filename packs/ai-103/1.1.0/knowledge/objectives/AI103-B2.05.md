# AI103-B2.05 — Build autonomous or semiautonomous workflows with safeguards and approval flow controls

Parent: AI103-B2; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Permit autonomous safe steps while requiring explicit review for constrained actions.

Combine application-side permissions, validation, oversight nodes/tool approval, and guardrails; preserve preview conditions.

## Failure or distractor distinction

Approval must precede the effect; an approval prompt after an API has changed data offers no protection.

## Scenario judgment

An agent may draft a contract summary, but sending it externally should follow a deliberate approval and validated recipient.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
