# AI103-C2.08 — Implement solutions that identify objects, components, or regions within images or video

Parent: AI103-C2; domain: C; **partial** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Separate semantic identification of an object/region from precise detector output and field-source grounding.

Choose a documented analyzer schema or dedicated detection contract; preserve coordinates/time ranges only when the chosen service returns them.

## Failure or distractor distinction

A model identifying an object in text does not guarantee a calibrated bounding box or complete object inventory.

## Scenario judgment

A quality-control requirement for exact defect regions needs a verified detection/localization API, not merely an image caption.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
