# AI103-E1.03 — Implement enrichment by using custom or built-in skills for text, images, and layout

Parent: AI103-E1; domain: E; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use a skillset to enrich the document tree with OCR/layout/text features and map results into the index.

Set skill contexts and input/output paths; create normalized images for OCR; use outputFieldMappings for enriched nodes.

## Failure or distractor distinction

A successful skill computation can still yield an empty searchable field if mapping paths are wrong.

## Scenario judgment

When OCR output exists in the enrichment tree but is absent from search results, inspect output mappings before re-running recognition.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
