# AI103-A2.02 — Choose appropriate deployment options

Parent: AI103-A2; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Select standard for flexible token billing, provisioned for capacity needs, and batch for asynchronous work; select processing geography separately.

Check SKU/model availability, quota, residency, and latency requirements; keep current managed compute distinct from classic VM-backed recipes.

## Failure or distractor distinction

A Global deployment does not enforce a chosen regional processing boundary; Azure VM quota cannot satisfy current Foundry managed-compute quota.

## Scenario judgment

A large overnight enrichment job and interactive low-latency agent require different deployment/throughput choices.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
