# AI103-B1.01 — Deploy and consume LLMs, small models, code models, and multimodal models

Parent: AI103-B1; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Consume an eligible deployed model through the SDK/API that supports its modality and operation.

Use the deployment name, correct project/model endpoint, credentials, and supported request shape; keep Python generation fixed.

## Failure or distractor distinction

A code-model label does not establish tool support, vision capability, or the right inference endpoint.

## Scenario judgment

When switching a text completion feature to image questions, verify multimodal eligibility and request content schema before keeping the old client call.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
