# AI103-A4.02 — Apply responsible AI instrumentation, including evaluators, safety evaluations, and explanation tooling

Parent: AI103-A4; domain: A; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use evaluations suited to answer quality, tool behavior, and instruction adherence; combine quality evidence with safety controls.

Supply the evaluator's expected conversation/context/tool schema and ground truth where needed; preserve preview labels.

## Failure or distractor distinction

A safety filter pass does not establish factual grounding, and tool-call correctness does not establish complete user-task resolution.

## Scenario judgment

An agent that calls the correct API but omits a requested deliverable needs task-completion evaluation as well as tool accuracy.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
