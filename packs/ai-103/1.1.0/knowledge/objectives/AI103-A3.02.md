# AI103-A3.02 — Monitor model performance, drift, safety events, and grounding quality

Parent: AI103-A3; domain: A; **partial** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Observe latency/tool activity through traces and score answer/retrieval quality against representative data.

Correlate evaluation run and trace IDs; retain model/prompt/source versions so regressions can be compared over time.

## Failure or distractor distinction

Stable latency does not imply stable grounding, and high relevance does not establish fidelity to evidence.

## Scenario judgment

A new deployment that runs faster but fabricates more needs quality regression analysis, not an all-green latency dashboard.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
