# AI103-B2.02 — Build agents that integrate retrieval, function-calling, and conversation memory

Parent: AI103-B2; domain: B; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Combine retrieval and validated function execution with a deliberate state/memory strategy.

Attach Search/file tools and functions; return correlated call outputs; store personal durable facts only in scoped memory.

## Failure or distractor distinction

Storing a retrieved policy as permanent personal memory can preserve outdated evidence after the source changes.

## Scenario judgment

The agent can look up current warranty terms, call a serial-number API, and remember preferred language without merging those three truth sources.

Authored inference from cited documented facts; not a reproduced or newly authored exam item.
