# AI103-C2.01 — Build a solution that analyzes visual context by using multimodal models

Parent: AI103-C2; domain: C; **ready** for bounded authoring. Official wording preserved. Documentation examples were not executed.

## Choice and configuration

Use a vision-capable chat model with actual images in the message when the task requires visual context.

Provide supported image URLs/base64 sources and a clear task; validate input limits and detail settings; constrain answers to visible evidence.

## Failure or distractor distinction

Text-only descriptions of a picture are not the same input as the actual picture, and visible context cannot establish hidden causes.

## Scenario judgment
